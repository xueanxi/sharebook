# 漫画图片生成功能设计文档

## 概述

漫画图片生成功能模块 (`comic_image_generation`) 是 ShareNovel 项目中专门用于生成漫画风格图片的核心组件。该模块基于 ComfyUI 平台，集成了 PuLID (Prompt-based Universal Latent IDentification) 技术，能够根据文本提示词和参考图片生成高质量、风格一致的漫画图片。

模块支持两种工作流程：
1. **单角色工作流**：使用一张参考图片生成单个角色场景
2. **多角色工作流**：使用两张参考图片生成包含多个角色的复杂场景

此外，模块还提供了完整的章节处理流程，能够自动读取、排序和处理小说章节的 JSON 数据，批量生成漫画故事板。

## 功能架构

### 核心组件

#### 1. ComicImageGeneration 类

模块的核心类，负责整个图片生成流程的协调和控制：

- **配置管理**: 通过 YAML 配置文件加载系统参数
- **工作流管理**: 加载和管理 ComfyUI 工作流模板（单角色和多角色）
- **接口封装**: 提供简洁的 API 接口供上层调用
- **错误处理**: 完善的异常处理和日志记录机制
- **章节处理**: 自动读取、排序和处理章节 JSON 数据

#### 2. ComfyUIWrapper 工具类

底层通信组件，负责与 ComfyUI 服务器的交互：

- **连接管理**: WebSocket 连接的建立和维护
- **工作流执行**: 提交工作流并监控执行状态
- **结果获取**: 获取生成的图片并保存到指定位置

#### 3. ChapterSorter 工具类

章节排序工具，负责章节文件的智能排序：

- **智能排序**: 根据章节号对文件进行排序
- **中文数字支持**: 支持中文数字章节号的识别和转换
- **多模式匹配**: 支持多种章节命名格式

### 技术栈

- **核心框架**: Python 3+
- **图像生成平台**: ComfyUI
- **关键算法**: PuLID 技术
- **通信协议**: WebSocket
- **配置管理**: YAML
- **日志系统**: 自定义日志模块

### 功能特性

#### 1. 双工作流支持

- **单角色工作流**: 使用一张参考图片生成单个角色场景
  - 工作流文件: `comfyui/novel_single_charator_refimage.json`
  - 参数: prompt, reference_image
  - 适用场景: 单个角色的特写、单人动作场景

- **多角色工作流**: 使用两张参考图片生成多角色场景
  - 工作流文件: `comfyui/novel_multi_charator_refiamge.json`
  - 参数: prompt, ref_image_1, ref_image_2
  - 适用场景: 对话场景、战斗场景、多人互动场景

#### 2. 参考图片支持

- **角色一致性**: 通过参考图片保持角色特征的一致性
- **风格迁移**: 应用参考图片的艺术风格到生成图片
- **精确控制**: 通过权重参数调节参考图片的影响程度
- **多角色支持**: 支持同时使用两张参考图片生成多角色场景

#### 3. 批量处理能力

- **单张生成**: 生成单个场景或角色的图片
- **批量生成**: 一次性处理多个提示词
- **角色变体**: 生成同一角色的不同表情、姿势或场景
- **章节批量处理**: 自动处理整个章节的所有场景

#### 4. 章节自动化处理

- **自动读取**: 扫描 `data/storyboards_prompt/` 目录下的所有 JSON 文件
- **智能排序**: 使用 ChapterSorter 对章节文件进行智能排序
- **场景解析**: 自动解析章节 JSON 中的场景数据
- **工作流选择**: 根据场景中角色数量自动选择合适的工作流

#### 5. 参数化控制

- **PuLID 权重**: 控制参考图片的影响程度 (0.0-1.0)
- **采样步数**: 控制生成质量和时间的平衡
- **CFG Scale**: 控制提示词的遵循程度
- **随机种子**: 支持可重现的生成结果

#### 6. 灵活的工作流管理

- **模板加载**: 支持不同的 ComfyUI 工作流模板
- **动态更新**: 运行时切换工作流配置
- **参数注入**: 动态修改工作流节点参数
- **工作流适配**: 根据场景需求自动选择合适的工作流

## 系统设计

### 配置系统

```yaml
comic_image_generation:
  paths:
    comfyui_input_dir: "D:/ComfyUI-aki-v2/ComfyUI/input/"
    single_character_workflow: "comfyui/novel_single_charator_refimage.json"
    multi_character_workflow: "comfyui/novel_multi_charator_refiamge.json"
    storyboards_prompt_dir: "data/storyboards_prompt/"
    output_root_dir: "data/storyboards_image/"
  generation:
    default_batch_size: 1
  error_handling:
    log_errors: true
    retry_count: 3
```

### 工作流架构

#### 单角色工作流 (novel_single_charator_refimage.json)

关键节点：
1. **CLIP文本编码 (节点1)**: 处理文本提示词
2. **LoadImage (节点26)**: 加载参考图片
3. **ApplyPulidFlux (节点32)**: 应用 PuLID 技术
4. **KSampler (节点5)**: 采样器控制生成过程
5. **VAEDecode (节点10)**: VAE 解码生成最终图像

#### 多角色工作流 (novel_multi_charator_refiamge.json)

关键节点：
1. **CLIP文本编码 (节点6)**: 处理文本提示词
2. **LoadImage (节点195)**: 加载参考图片1 (ref_image_1)
3. **LoadImage (节点200)**: 加载参考图片2 (ref_image_2)
4. **ReferenceLatent (节点198)**: 处理参考图片1的潜在表示
5. **ReferenceLatent (节点202)**: 处理参考图片2的潜在表示
6. **KSampler (节点31)**: 采样器控制生成过程
7. **VAEDecode (节点8)**: VAE 解码生成最终图像

### 数据流程

```
章节JSON读取 → 章节排序 → 场景解析 → 角色数量判断 → 工作流选择 → 参数注入 → ComfyUI执行 → 结果获取 → 图片保存
```

### 章节处理流程

1. **扫描阶段**: 扫描 `data/storyboards_prompt/` 目录下的所有 JSON 文件
2. **排序阶段**: 使用 ChapterSorter 对章节文件进行智能排序
3. **解析阶段**: 解析每个章节 JSON 文件中的场景数据
4. **分类阶段**: 根据场景中角色数量选择单角色或多角色工作流
5. **生成阶段**: 按顺序生成每个场景的图片
6. **保存阶段**: 将生成的图片保存到对应章节的目录中

## 使用场景

### 1. 小说角色可视化

将小说中描述的角色转换为具体的漫画形象：

```python
comic_gen = ComicImageGeneration()
image_paths = comic_gen.generate_image(
    prompt="一个英俊的年轻男子，黑发，穿着现代服装，站在城市街道上，动漫风格",
    reference_image="path/to/character_reference.jpg",
    save_dir="characters/main_character"
)
```

### 2. 多角色场景生成

使用两个参考图片生成多角色互动场景：

```python
comic_gen = ComicImageGeneration()
image_paths = comic_gen.generate_multi_character_image(
    prompt="男女主角背靠背站立，男性持盾，女性握剑，气氛严肃，背景为海洋",
    ref_image_1="path/to/male_character.jpg",
    ref_image_2="path/to/female_character.jpg",
    save_dir="storyboards/battle_scene"
)
```


### 3. 章节批量处理

自动处理整个章节的所有场景：

```python
# 处理单个章节
chapter_results = comic_gen.process_chapter(
    chapter_json_path="data/storyboards_prompt/第一章.json",
    save_dir="storyboards/chapter_01"
)

# 处理所有章节
all_chapters_results = comic_gen.process_all_chapters(
    storyboards_prompt_dir="data/storyboards_prompt/",
    save_dir="storyboards/"
)
```

## 实现细节

### 章节JSON数据结构

章节JSON文件应包含以下结构：

```json
{
  "chapter_title": "第一章 遇强则强",
  "scenes": [
    {
      "scene_id": 1,
      "prompt": "主角站在山巅，俯瞰下方云海，白袍飘飘",
      "characters": ["主角"],
      "character_references": {
        "主角": "path/to/main_character.jpg"
      }
    },
    {
      "scene_id": 2,
      "prompt": "主角与神秘人对峙，气氛紧张",
      "characters": ["主角", "神秘人"],
      "character_references": {
        "主角": "path/to/main_character.jpg",
        "神秘人": "path/to/mystery_character.jpg"
      }
    }
  ]
}
```

### 工作流选择逻辑

系统根据场景中的角色数量自动选择工作流：

```python
def select_workflow(self, scene_data):
    character_count = len(scene_data.get("characters", []))
    
    if character_count == 1:
        return self.single_character_workflow
    elif character_count == 2:
        return self.multi_character_workflow
    else:
        # 对于超过2个角色的场景，使用多角色工作流并选择前两个主要角色
        return self.multi_character_workflow
```
